# Phase-I exploratory results

These files describe the **adaptive-development** state at the Phase-I submission snapshot. They are not prospective validation.

## Current portfolio

- 52 primary model/decoder variants
- 6 mechanism families
- 50-protein development panel
- 659 annotated target residues
- at least one current candidate reaches 39/50 proteins
- 270/659 annotated target residues are recovered somewhere in the current portfolio

## Interpretation boundaries

- Portfolio union is a complementarity/headroom diagnostic, not single-predictor performance.
- Specialist/generalist labels are oracle development labels, not a deployable router.
- `Q_ONLY` is candidate-matched-control evidence, not quantum advantage.
- The 50-protein panel has been adaptively inspected and is treated as development data.
